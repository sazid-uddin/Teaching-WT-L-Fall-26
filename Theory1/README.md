10. HTTP Protocol
    - HTTP is Connectionless and Stateless:
        - Connectionless: Each request is independent of the previous request. The server does not keep track of the client's state between requests.
        - Stateless: The server does not store any information about the client's state between requests. Each request is treated as a new request, and the server does not remember any previous interactions with the client.
