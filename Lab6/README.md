### Lab 6 - Nov 1

#### Topics Covered:

##### HTML Forms:

1. Form structure
    - `<form>`, `action`, and `method`
    - Submitting and resetting forms
2. Form controls
    - Text, email, password, number, and range inputs
    - Radio buttons and checkboxes
    - Select menus and options
    - Text areas
    - Labels and field names
3. Grouping and constraints
    - `<fieldset>` and `<legend>`
    - `min` and `max`
    - Input `pattern`

##### JavaScript Form Validation:

1. Handling form submission with `onsubmit`
2. Reading input values from the DOM
3. Validating required fields
4. Checking string length
5. Checking email suffixes
6. Preventing form submission with `return false`
7. Showing and clearing inline error messages
8. Calling functions with `onclick`

#### Files:

- `form.html` - account creation form with form controls and validation feedback
- `script.js` - JavaScript form validation
