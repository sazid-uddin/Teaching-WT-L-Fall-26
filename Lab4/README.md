##### JavaScript:

4. Syntax, Statements, and Output

    - Comparison (`==` vs `===`) and logical
    - Operator precedence
6. Events, Functions, and Control Flow
    - Functions
    - Events and `addEventListener()` (event + what to do)
    - `if` / `else`
    - Loops
